## Local AI projects I'm following

Checked on 27 Sep 2026. These tools run on my own computer, so my data stays local.

| Project | What it does | Effort | License |
|---|---|---|---|
| [Jan](https://github.com/janhq/jan) | ChatGPT-style desktop app that runs fully offline | No code | Apache-2.0 |
| [Ollama](https://github.com/ollama/ollama) | Downloads and runs open models; most local tools plug into it | One command | MIT |
| [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) | Chat with my own PDFs and documents | No code | MIT |
| [Open WebUI](https://github.com/open-webui/open-webui) | Browser chat interface for Ollama, supports several users | Some setup | Custom (BSD-3 plus branding clause) |
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | The engine behind many local AI apps | Technical | MIT |
| [llamafile](https://github.com/Mozilla-Ocho/llamafile) | A whole model packed into one runnable file | Some setup | Apache-2.0 |
| [LocalAI](https://github.com/mudler/LocalAI) | Local server that speaks the OpenAI API | Technical | MIT |
| [Self-hosted AI Starter Kit](https://github.com/n8n-io/self-hosted-ai-starter-kit) | n8n, Ollama, Qdrant and PostgreSQL in one Docker setup | Technical | Apache-2.0 |
| [PandasAI](https://github.com/sinaptik-ai/pandas-ai) | Ask questions about CSV files and databases in plain language | Technical | MIT (except /ee) |
